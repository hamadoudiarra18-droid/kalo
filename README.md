# Kalo — calendrier lunaire du Mali

Application Android (WebView) : le calendrier lunaire Kalo, hors ligne, avec widget, rappels d'événements,
carte WhatsApp et trois modes d'interface (Kalo, Nuit, Bogolan).

## Contenu
- `app/src/main/assets/index.html` — le calendrier (toute l'interface).
- `app/src/main/java/com/kalo/calendrier/` — `MainActivity` (écran + pont avec la page), `KaloWidget` (widget), `ReminderReceiver` (rappels).
- `app/src/main/res/` — widget, icônes, couleurs.
